# Przypadki - Polish Cases & Core Grammar

Przypadki is a dependency-free, interactive course for moving from basic
Polish sentence building toward intermediate reading and speaking. The seven
cases are the spine of the course, but the guide also covers gender, number,
verb aspect, motion, negation, pronouns, adjective agreement, and sentence
building.

## Lessons included

- Start with a four-level path from sound/spelling habits to intermediate clause
  control.
- Learn all seven Polish cases: nominative, genitive, dative, accusative,
  instrumental, locative, and vocative.
- Compare case questions, core meanings, common prepositions, and starter
  endings in one reference table.
- Use an interactive case lab to see how the same noun phrase changes by role.
- Practice high-frequency case triggers: possession, negation, direct objects,
  motion, location, tools, recipients, and forms of address.
- Build noun phrases with gender and adjective agreement.
- Contrast imperfective and perfective verbs in everyday learner sentences.
- Work through a sentence studio and a cumulative twenty-question practice set.

## Run locally

or serve the directory with any static HTTP server.

```powershell
npx serve .
```

## Language note

The guide teaches productive beginner-to-intermediate patterns, not a full
declension dictionary. Polish endings vary by gender, number, animacy, stem
shape, and lexical class, so the tables deliberately begin with reliable
starter patterns and examples. Add native-speaker review before treating the
site as a comprehensive reference.

Starter content was cross-checked against Wikibooks' Polish
[basic grammar](https://en.wikibooks.org/wiki/Polish/Basic_grammar) and
[noun cases](https://en.wikibooks.org/wiki/Polish/Noun_cases) pages, plus the
Polish Wiktionary declension table for
[student](https://pl.wiktionary.org/wiki/student).
